# Project Statement



## Student_Dashboard



### Problem Statement



In day to day life, students often have to perform minor calculations pertaining to their academics like calculating their grades, attendance, and their FFCS slot.



These calculations could become monotonous and tedious in certain occasions.



My project, Student Helper, is a compilation of these three functions which could be performed using a single menu driven program.



### Objective



The main objective of my project was to design and develop a simple yet efficient Python program to enable the users to perform these daily calculations.



The program enables the user to:



- Evaluate their grades based on the entered marks and class average,



- Track their attendance,



- Calculate the required classes for 75% attendance,



- Calculate their FFCS slot based on their attendance and grades.



### Working of the Project



After opening the program, a menu named 'Student Helper' appears which provides the option of choosing between Grade Evaluation, Attendance Tracking, and FFCS.



In the Grade Evaluation, the user has to enter the names and marks for each course. The mark is compared to the class average and a grade is assigned.



In Attendance Tracking, the total number of attended, total number of and upcoming classes are used to track the attendance and the number of classes required to maintain 75% attendance.



In FFCS, the attendance and grade of the student is entered and based on certain conditions, the FFCS slot is calculated.



### Why I Made This Project



I made this project in order to gain experience in Python by developing an application which could be useful for other students in their academics. By developing this program, apart from understanding the concepts of Python, I was able to merge various concepts and develop a fully functional program.



### Conclusion



Student Helper, my project, is a simple Python application which could be used to perform certain basic functions related to academics.



This project helped me learn the intricacies of developing a Python program. There is a vast scope of enhancement of this project by adding a Graphic User Interface, improving the operations, and including more relevant functions related to students' academics.
