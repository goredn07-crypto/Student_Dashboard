# Student_Dashboard



## Description



Student Helper is a simple Python-based project, which aims to ease the pain of various student-related tasks.



Instead of wasting time calculating grade, attendance, and calculating your FFCS slot separately, this project will help you do all of that in a single place and with minimal effort. This project is menu-driven and makes it easy for the user to select the operation and enter the required data.



The project currently offers 3 key features, including



1. Grade evaluation



2. Attendance calculator



3. FFCS slot calculator



## Features



### 1. Grade Evaluation



The feature asks the user to provide the following data:



Number of courses



Course name



Marks obtained



Class average



Then, it compares the student's marks with the class average and allocates a grade from S to F.



In addition, it prints a simple report card with the course name, marks obtained, class average, and the allocated grade.



### 2. Attendance Tracker



Attendance tracker cross-references the data provided by the user, including



Total classes attended



Total classes scheduled



Number of upcoming classes



It then cross-references the above data to calculate the current attendance and elaborate on the number of classes that need to be attended to maintain 75% attendance.



### 3. FFCS Slot Calculator



By providing the total attendance and the grade, the user will be able to obtain the corresponding FFCS slot.



Depending on the combination of grade and attendance percentage, the FFCS slot calculator will return different slots.

## Getting Started



To run the Student Helper project on your machine, you will need to have Python installed. After installing Python, you can download or clone the repository to your local machine. Then, open the terminal or Python IDE and navigate to the directory, where the Student Helper project is located.



Finally, you should be able to run the following command:



```bash



python main.py



```



After that, you will be able to select the desired option by entering the corresponding number and providing the necessary data.
